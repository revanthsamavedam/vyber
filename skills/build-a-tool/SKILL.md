# Build a tool

1. Smallest thing that fully works — one or two files beats five.
2. Complete file contents, no placeholders, no external assets or keys.
3. The builder's FilePlan goes to the reviewer before anything is written; if vetoed, fix the named issues once, don't argue.
4. Report what was built and how to open/run it.
