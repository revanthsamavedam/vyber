# Deep research

1. Restate the question in one line — if it's ambiguous, note the interpretation you chose.
2. Gather from the best available sources first (primary over commentary).
3. Return Findings: summary first, then discrete points. Label inference explicitly.
4. Name gaps: what you could not verify matters as much as what you found.
